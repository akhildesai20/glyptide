Documentation

            
Get started

          

        

        

          

            
Install locally

            

              Until the package is published to npm, use the local package from
              this repository or download the built files from
              packages/glyptide/dist.
            

            
# From the Glyptide repository root
npm install ./packages/glyptide
# React adapter (optional)
npm install ./packages/glyptide-react

          

          

            
Vanilla JavaScript

            
import { createGlyptide } from "glyptide";
import "glyptide/styles.css";

const el = document.querySelector("#out");
const g = createGlyptide({
  element: el,
  pattern: "new-word-settle",
});

g.start({
  text: "Thoughtful motion makes interfaces feel alive.",
});

          

          

            
Real streaming

            

              Pass chunks from your existing AI or data source. Glyptide does not
              call an API.
            

            
const g = createGlyptide({
  element: el,
  pattern: "new-phrase-fade",
});

for await (const chunk of stream) {
  g.append(chunk);
}
g.finish();

          

          

            
Accessibility

            
    
              
  • Respects prefers-reduced-motion
    • 
              
  • Pause controls for persistent motion
    • 
              
  • Coherent text remains selectable and copyable
    • 
              
  • Live regions announce completion, not every token
    • 
              
  • Keyboard-operable playground and review actions
    •

<Glyptide

  autoPlay
/>

          

          

            
Principles

            
    
              
  • Preserve what exists — only incoming content moves
    • 
              
  • Use springs sparingly for spatial change
    • 
              
  • Keep the reader in control
    • 
              
  • Communicate actual state, never fake progress
    •
